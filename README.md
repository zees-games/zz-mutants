Mutants for Zombie Zone, a recommended Workshop pack. It ships the Parasite Host today; the 13 special infected (leaper, strangler, bloater, ram, spitter, rider, brute, sleeper, screamer, crawler, riot, mutant, oil monster) are still built into the game and move here next.

Workshop page: https://moddingcommunity.com/a/156-mutants

The pack owns its view script (`spawn.view`): the game loads it with the game's own zombie view as parent, and falls back to a built-in body when the pack is absent. See docs/mutant-provider.md and CREDITS.md.
